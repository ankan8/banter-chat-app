# 💬 Banter Chat Application

A real-time chat app built with **WebSockets**, **Node.js**, **MongoDB**, and a clean **React.js** frontend.  
Built for speed, scalability, and user engagement — Banter Chat delivers instant messaging with <50ms latency and a smooth user experience.

---

## 🚀 Features

- 🔁 **Real-Time Messaging**: WebSocket-based chat with lightning-fast delivery (<50ms)
- 🔄 **Live Updates**: Messages broadcast instantly to all connected users
- 💻 **React Frontend**: Interactive and user-friendly UI without any external CSS frameworks
- ⚙️ **Scalable Backend**: Node.js and MongoDB architecture supports high-concurrency use
- 📈 **Optimized Experience**: Increased average session duration by 20% via frontend and backend improvements
